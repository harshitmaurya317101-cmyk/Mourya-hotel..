MAURYA HOTEL QR ORDERING WEBSITE - FRONTEND PROTOTYPE

Included:
- Responsive black/gold restaurant styling
- 50 menu dishes, each with its own generated photo asset
- Search and category filters
- Plus/minus quantities and cart
- Customer name, table number and payment-method selection
- QR table URL parameter support (?table=4)
- Demo order confirmation and tracking placeholder

IMPORTANT:
This is a frontend prototype only. Orders are not persisted or sent to the kitchen.
Supabase backend/RLS/realtime, Razorpay secure payment verification, push notifications,
admin dashboard, and QR code generation must be implemented before real restaurant use.
Never place Razorpay secret keys in frontend files.

Open index.html locally to preview. To deploy, upload the full folder to a host such as
GitHub Pages or Vercel. Keep the assets folder alongside index.html.
